# 跨章整合、来源绑定与证据复用

## 按素材依赖推进

实证章的已接受稿件为总括章节提供数据、方法、结论和限制；用户指定的原始总结底稿为总结章保留作者叙事。后者还需对照总括与实证章，不能仅拼接结论。已有各章 PPT/音频可提供制作流程经验，学术论断仍以论文为依据。

正文统稿和答辩材料各保留一个内容写入者。章节作者核自己的接口，资源执行者操作原生应用或共享 NLM；操作成功不代表其代替作者接受结论。按 UUID、任务和实际文件绑定当前职责，数字 surface 编号只供定位。

作者未冻结总稿时，PPT 可按固定章节输入清单写文稿、映射、讲稿和版式。保留章内物理页/印刷页与定位文本，不预填全篇页码。作者提供真实冻结件后按内容变化映射核受影响单元，替换最终身份和页码；未变材料可复用原审校。总稿当前候选与正式冻结分别记录，不以静默、约定路径或文件名 FINAL 推定完成。

## 内容母本与版本差异

- 一个受控母本派生文稿、PPT 文字与表格、notes、逐字稿、来源索引。历史删除稿另存；现代导出仅选择明确活动单元，不能因索引遍历重新带回已归档文本。
- 逻辑标签（例如某章、理论框架）先解析到清单中具体文件及 SHA，再绑定真实 NLM source；标签本身不是服务器 ID。
- 数字、符号、单位、表格行列、图的节点和连接方向、研究限制均属于内容。排版变化的等价证明须覆盖这些信息及讲稿。
- 文件 SHA 不同、XML 序列化不同、语义不同分别报告。文档/图像 XML 可按展开后的元素名、属性、文字和子节点比较；不要凭前缀或冗余命名空间位置认定图义改变。不可忽略几何、连线或真实文字差异。
- Word 可把复杂域写成 `fldSimple`，某些默认编号或脚注位置可以省略。审计解释器须读取有效值及域语义，不为满足只认一种 XML 写法的检查器修改正确正文。中英文混合单元格按完整单元格内容与其有效样式判断。

检查器误报时，保留原 FAIL、原文件与取证，修正判定并另发纠正记录。正确文稿没有变化就不重生成、不重导出；受影响检查要重跑。新检查器的 PASS 也不能抹去真实未解决内容错误。

## 最窄审查补全

本地数值核查、NLM 审读、原刊核源和视觉各有范围。对误引用先联合同一轮既有回答及原生引文；语义内容和来源已齐时关闭定位错误。真实未读的图内微观边、表尾计数或段落则只补该缺口，保持同稿同源同轮，并保留原题/补题对应。完整返回且零原生引用的回答不计入有据审校；它和未发送的 TLS 失败分别记账。

六主题本身不保证穷尽。以实际覆盖和本地裁决决定是否合格，不用问题数量、HTTP 200、字数或同事的 DONE 代替。固定原范围后不因 NLM 泛化建议增加审查轮；真实新错仍需解决并按受影响版本复核。

## 完成状态保持独立

来源定位、数值相容、唯一实证链、完整重估、稿件接受、原生导出、视觉、音频创建、下载解码、机器转录核对和人工听审分别记录。历史模型没有重估成功的限制要传入摘要、PPT 和音频提示，不能随“全量复盘完成”消失。ZIP 要回读成员和实际字节，数量由当前清单计算；同一成果的多种副本不算多次审校。
