# Current shared task and result contract

This source consumes [MAC0.4.67](https://github.com/lzhs1995/multi-agent-collaboration/releases/tag/v0.4.67).
Resolve and SHA-pin the complete canonical shared skill for new work. Existing
attempts retain their issued source, nonce, process/session and input evidence.
Keep a healthy original executor working; after bounded genuine provider
failures, authorized Codex SOLO work continues with `solo_self_review`.
Do not replace an original executor or retry an uncertain input to restore transport.

Read relevant exact peer reviews in a separate work boundary before generating
an output. Record adopted findings and input pins, then check for late increments.
When diverting the sole reviewer, retain pending package hashes, unfinished
units, original review owner and a concrete return condition. Preserve WIP2;
inquiry counts and frozen independent recomputation do not complete peer review.

Use the original supervisor's read-only `executor_reask.py coverage` for its
two issued executor scopes. Missing enrollment, authority expiry, unread replies
and observation drift remain distinct. File-only sweeps give each executor a
finite slice within the original ten-second sweep budget. A slow or timed-out
slice remains incomplete; ordering hints supply neither authorization nor replay.
Successor previews tolerate validated poll observations while continuing to
reject changed task/reply/reservation/pending semantics and stale authority.

`STANDBY` and `HOLD` describe waiting, rather than a mailbox status. Use the
original `WAITING_DEPENDENCY` status with its explicit trigger, wait owner and
finite ordered due/deadline fields. Shared `executor_reply_preflight.py` validates
an exact candidate state/body by absolute path and SHA; `authority_verified=false`.
It neither publishes nor consumes. The original supervisor checks authority,
and the original executor FULL-reads and exact-SHA consumes through its controller.

New scoped orders pin their complete controller and separate acceptance,
progress and final outputs. The zero-input `scoped_work_completion.py` planner
can `--prepare-body` and return ready arguments. Capture stdout, stderr and
return code: an uncertain submission can emit its receipt on stderr and exit75.
Retain the supplied original reconciliation arguments, not a substitute marker,
surface or body. Formal harness callbacks still use their original dedicated route.

The isolated `word_restricted_broker.py`/`word_restricted_pdf.py` lane supports
only approved new owned PDF work with fixed checked-source native templates.
It retains the old ACTIVE ticket, invocation count, ordinary resource mapping
and foreign UNKNOWN. `COMPLETE_WITH_FOREIGN_UNKNOWN` is restricted cleanup,
not ordinary release or persistent Zotero citation insertion. A true-citation
task still requires its complete native consumer, saved/reopened live-field
checks and original resource authority. Never replay an unresolved NLM request.

Canonical aliases, release installation, actual process/hook loading, original
native receipt, FULL reading and accepted manuscript progress are separate.
A legacy Chinese alias or old static hook can remain different in a live client;
preserve in-flight pinned paths and record that gap. Measure accepted manuscript
outputs and actual work/coordination time before claiming efficiency improved.
This repository documents shared contracts; MAC alone owns their implementation.
