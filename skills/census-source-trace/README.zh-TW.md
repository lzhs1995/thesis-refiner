# 普查來源追溯

[English](README.md)

可攜的指令型技能：定位人口普查與統計年鑑原表、復用已驗下載，並保存候選觀測的來源與統計意義。

本技能提煉自既有取件流程，使用所在環境已有的瀏覽器、下載工具與試算表／PDF 讀取器。套件未附爬蟲、憑證管理器、資料庫連接器或模型估計程式。

## 使用

1. 讓 agent 讀取 [SKILL.md](SKILL.md)，提供目前專案的任務／斷點及目標原表。
2. 在私有專案資料夾中調整 [task.example.json](examples/task.example.json)。範例完全虛構且只做離線工作；欄位是任務說明，不是可執行 API。
3. 請 agent 復用已驗來源、登記證據缺口，並在確有取件需求時沿用既有授權工具。

範例指令：

> 使用 census-source-trace。讀取我的專案斷點與來源登記表，按指定普查年份及地域定位家庭戶數原表，復用已驗下載，交付含頁碼／儲存格、單位、統計對象與邊界依據的候選資料，明列尚未確認的口徑。

| 客戶端 | 入口 |
| --- | --- |
| Codex | [SKILL.md](SKILL.md)；專案脈絡見 [AGENTS.md](AGENTS.md) |
| Claude Code | [CLAUDE.md](CLAUDE.md)，匯入共用入口 |
| Gemini 或其他 agent | [GEMINI.md](GEMINI.md)，再讀共用入口與技能 |

若客戶端不會自動發現此資料夾，直接要求讀取這些檔案；需要專案入口時只加入連結，保留既有規則。安裝位置與工具 API 依所在環境決定。提供入口檔不代表客戶端已實際載入或執行。

## 產物與邊界

[資料契約](references/record-contract.md)分開記錄來源身分、原值、轉換及接受狀態。候選資料、研究正式採用與模型估計分別留證。真實憑證、本機路徑、原始資料、回執及專案綁定保留在可發布資料夾之外。

歷史證據包含官方統計、CNKI 與 EPS 的真實取件試點及已保存的快取核驗；這些證據尚未證明自動再次登入、一般化線上故障恢復或多資料庫穩定端到端作業。完整範圍見[驗證界線](references/validation-boundaries.md)。

此為供審閱的候選版本。一位 Codex agent 已明確讀取技能並使用內附離線虛構範例，核對宣告欄位、保存範例雜湊，將觀測記為 `needs_source`；實際原表取得、觀測接受及正式採用均為 0。範例本身已說明缺少證據，因此這不是盲測。自動發現、Claude／Gemini 實際運作、線上取件、再次登入及一般化故障恢復仍未驗證；本次演練不證明公開發布。標誌為本套件原創 SVG，沒有外部圖片或字型依賴。
